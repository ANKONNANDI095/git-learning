# Simple Contact Form

A minimal web page with a contact form built using HTML, CSS, and JavaScript.

## Features

- Responsive contact form layout
- Bright and dark mode theme toggle
- Styled input fields and button
- JavaScript form submission handling
- Confirmation message displayed after submit

## Files

- `index.html` — markup for the form and page structure
- `style.css` — styling for the page, theme support, and form
- `scrip.js` — JavaScript to handle theme toggling and form submit events

## Usage

1. Open `index.html` in a browser.
2. Use the theme toggle to switch between bright and dark mode.
3. Fill in your name, email, and message.
4. Click the **Submit** button.

The page will show a confirmation message after submitting.
